# Travel Management System

##  Project Description

The Travel Management System is a command-line based Python project designed to manage travel-related information easily. It allows users to add, view, search, 
and manage travel details through a simple menu-driven interface.

##  Objectives

- To manage travel details in an organized way.
- To provide an easy-to-use command-line interface.
- To store and retrieve travel information efficiently.
- To reduce manual work in maintaining travel records.

##  Technologies Used

- Python
- Excel
- OpenPyXL

##  Features

- Add Travel Details
- View Travel Details
- Search Travel Records
- Display All Travel Records
- Store data in an Excel file
- Simple menu-driven interface
